## Overview

Saturn is an expert-inspired, training-free pipeline for natural-language-driven tabular data discovery. A multi-agent framework constructs a User Preference-based Ontology (UPO) from query requirements and table evidence. Saturn reuses the ontology's concept-specific procedures to create compact table profiles and aligns queries to the same profile space for retrieval, without task-specific alignment training.
